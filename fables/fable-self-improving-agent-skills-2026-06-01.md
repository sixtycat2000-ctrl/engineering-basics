📖 每日工程寓言 — 自我进化的手艺

---

在迷宫城深处，住着一位信使，名叫阿练。

迷宫城不是普通的城市。这里的街道每天都会变——铁匠铺今天在东巷，明天就搬到了西街；通往港口的大路可能一夜之间塌了一半，但旁边又多出一条谁也没走过的小径。城里的每条路都只对走过一次的人敞开，等你走第二次，它已经换了模样。

阿练的工作很简单：每天收到一张送货单，把包裹送到指定的地方。

问题是，他每天醒来都不记得昨天走过哪条路。

不是他记忆力差——是迷宫城的规矩。日出时分，所有的脚印都会被抹去，所有的路标都会重置。每一个清晨，阿练站在城门口，看着眼前密密麻麻的巷道，就像第一次来这座城市一样。

一开始，他靠蛮力。拿到地址就往里冲，碰壁就回头，再换一条。送到是送到了，但太阳落山时他常常累得走不动——有些路绕了三圈，有些死胡同他钻了两次，还有一次他花了整整一个下午才发现，目的地就在他出发点旁边的那条巷子里，只是入口藏在一棵老槐树后面。

"这样下去不行。"他对着空气说了第三百遍。

转折发生在第三百零一天。

那天他接到一个送到旧港的任务。和往常一样，他冲进迷宫，碰壁，回头，再试。但这次，他没有像往常一样在碰壁后立刻转身——他在墙上划了一道痕迹，然后打开随身带的破旧本子，写了一行字：

> 旧港方向：第二条巷子左转是死路，有铁栅栏封死，不要走。

第二天，同样的任务又来了。他翻出本子，看了那行字，避开铁栅栏，改走第三条巷子。这次他少碰了一面墙，省了半个时辰。

他在本子上又加了一行：

> 第三条巷子走到尽头有一个岔口，左边通向旧港市场，右边是居民区，走左边。

第三天，他又优化了一步。他发现第三条巷子的岔口旁边有一条被灌木遮挡的小路，可以直插旧港码头，比走市场绕一大圈快了三倍。他赶紧记下来，还画了个简陋的地图。

到了第五天，他翻开本子，发现自己已经把去旧港的路线压缩成了一张精简的路线卡。从原来要花大半天、碰十几次壁，变成了沿着记下来的路线，一炷香就走到了。

"有趣，"他想，"第一次去旧港花的时间最长，但那一次的'学费'最值。后面每一次都只是照着走而已。"

他开始把这个方法用到所有目的地。

但阿练很快发现了新的规律。有些目的地，他试了三四次还是找不到好路——不是因为路太难，而是因为那个地方本来就不该用"走迷宫"的方式去。比如城西的集市，其实沿着城墙外面的大路走两里就到了，根本不需要钻巷子。他只是在第一天冲进迷宫里，就再也没想过"也许该绕到外面看看"。

于是他在路线卡上加了一条规则：

> 第一步：先站在城门口看看外面有没有大路。如果有，走大路。大路走不通，再进迷宫。

这条规则救了他无数次。有些地方确实只需要一页纸的说明就够了，他不需要每次都亲身走进迷宫去重新发现。

---

消息传开了。其他信使听说阿练的本子，纷纷来借。有人借了去旧港的路线卡，照着走了一遍，果然很快就到了。又有人把自己摸索的路线抄了一份送过来。

阿练的本子越来越厚。他把它重新整理了一下，每条路线单独一张卡片，标注了"最优走法"、"备选方案"和"常见陷阱"。他把整套卡片放在城门口的木架上，谁都可以取用。

有个年轻的信使翻着卡片说："这不就是把你自己走过的路记下来吗？有什么稀奇的？"

阿练笑了笑："你说的对。但如果你每次都要亲自走一遍才知道铁栅栏后面是死路，那你一辈子也送不了几个包裹。我在第一天把路走通了，后面的人连学费都不用付。"

他顿了顿，又说了一句让年轻信使想了很久的话：

"最贵的那一趟，不是浪费——它是后面所有趟的预付金。"

---

💡 **概念解析：Self-Improving Agent Skills（自我进化技能）**

这则寓言讲的是 AI Agent 的**自我进化技能**机制——以 Autobrowse（Browserbase）为代表的一类系统设计。

核心问题：AI Agent（尤其是浏览器 Agent）每次执行任务时都从零开始，就像阿练每天不记得昨天走过的路一样。这造成了巨大的重复成本——同一个网站被反复探索，同样的陷阱被反复踩中。

解决方案是一个**三阶段闭环**：

1. **练习（Run）**：让 Agent 在真实任务上运行，碰壁、犯错、浪费 token——这些"学费"是有意为之的
2. **复盘与迭代（Study → Iterate）**：Agent 回顾自己的执行轨迹，识别哪些步骤是浪费的，哪些捷径是有效的，把观察结果记录在策略草稿中。反复迭代直到**收敛**——连续几次尝试没有显著改进就停止
3. **毕业（Graduate）**：将收敛后的最优路径写入一个**可读的技能文件**（markdown + 辅助脚本），不再是黑盒模型权重或向量数据库，而是人类和 Agent 都能看懂的操作手册

寓言中的几个关键隐喻：
- **迷宫城每天重置** → Agent 没有持久记忆，每次执行都从零开始
- **本子上的路线卡** → 技能文件（SKILL.md），记录最优路径、备选方案和陷阱
- **"先看外面有没有大路"** → 先用确定性工具（fetch/Python parser）探查，确认不够再启用高成本的 Agent 探索
- **"最贵的那一趟是预付金"** → 首次执行的昂贵成本是故意的，它为后续所有执行买单
- **城门口共享的卡片架** → Browse.sh 等公共技能目录，技能的价值在于复用

这不是让模型本身变得更强，而是让 Agent 拥有了**经验积累**的能力。推理能力是瓶颈的时代可能正在过去——**记忆**才是下一个瓶颈。
