# 老师傅的五把锁

年轻木匠赵明远学艺十年，终于获准独立开作坊。

临行前，师父交给他五把铜锁。锁身各刻着一个字，编了号。师父说："作坊开张前，按顺序挂。错一把，全盘皆输。"

赵明远心想，锁嘛，挂上就是了，何必讲究顺序。

---

他挑了最漂亮的那把——五号锁，锁身刻着"验"字，花纹繁复，是师父亲手打的检验锁。他把它挂上大门，请了三个帮工，热热闹闹开了张。

开张第一天，他接了个大单。可当晚，设计图被人偷了。

他追查不出是谁——大门上只挂着检验锁，查的是成品合不合格，防不了家贼。

他慌忙翻开箱子，取出一号锁。

一号锁刻着"秘"字。它不是挂在门上的，而是装在每个工具箱内部的：每个帮工只能开自己那口箱子，图纸和秘方锁在师父传下来的暗格里。装好暗锁，图纸再没丢过。一号锁不动声色，但它让所有最要紧的东西——配方、客户名单、定价策略——从不暴露在众人眼前。

---

图纸安全了，可木材耗得飞快。

三个帮工各干各的，没人统筹。一周下来，木料用超了两倍。赵明远找不出哪里浪费的——一号锁保住了秘密，但管不住花销。

他取出二号锁。

二号锁刻着"度"字。是一把量尺锁——每取一份料，先过量尺，超额自动卡住。木屑和下脚料也一一称量，每日汇总。挂上二号锁后，花销一目了然。帮工再不能随心所欲地取料，赵明远也第一次看清了每天到底用了多少。

---

木料管住了，新的麻烦来了。

上周做的一批椅子，这周客户要求复刻。可尺寸怎么也对不上。他翻遍工坊，找不到上周的原始记录。帮工们各自记在脑子里，传着传着就变了。

他取出三号锁。

三号锁刻着"录"字，是一枚日期锁。每完成一批活，帮工必须把尺寸、木料、工艺记在木牌上，挂上三号锁，存入档案架。木牌一旦上锁，任何人不得涂改。任何时候要回溯，翻出上锁的木牌，上周二那批椅子的每一个细节都在。赵明远终于可以一句话回到任何一个"那天做对了"的状态。

---

一切井井有条了。但赵明远总觉得不安。

帮工们在后院干活，他看不见。有人在偷工减料吗？有人在私接外活吗？他不知道。一号锁保住了秘密，二号锁管住了用量，三号锁记住了历史——可此刻正在发生的事，他一无所知。

他取出四号锁。

四号锁刻着"察"字，不是锁门的，而是锁在每扇窗户上的透光铜片。透过铜片，后院的一举一动尽收眼底：谁偷了懒，谁换了料，谁在工时里磨洋工，清清楚楚。连帮工之间的私语，都被铜管传到前厅。四号锁不防什么，但它让你看见一切——包括那些本不该发生、却正在发生的事。

---

现在，赵明远终于理解了那把五号锁的真正意义。

检验锁不是挂在门面上给客人看的。它是当前面四把锁全部就位之后，才能发挥作用的。

没有一号暗锁保护秘密，检验的基准可能被篡改。

没有二号量尺控制消耗，检验的标准没有意义——你连用了多少都不知道，检验什么？

没有三号日期锁记录历史，检验无法对比——上个月的合格品和这个月的不合格品之间差了什么？无从查起。

没有四号透光锁照亮暗处，检验只是走形式——你看不见的过程里，鬼知道发生了什么。

五把锁全挂上了。工坊运转顺畅，半年无一事。

---

隔壁街新开了一家作坊。那个年轻木匠也有一模一样的五把锁。

他只挂了五号。

三个月后，他的作坊关了。

---

## 💡 概念解析：Agent 安全工具安装顺序

这则寓言讲的是 **Agentic Systems 的安全工具安装顺序**——在构建 AI Agent 系统时，必须按特定顺序部署五层安全工具，每一层依赖前一层就位。

这个框架来自安全工程师 Ronin (@DeRonin_)，他在 141K 浏览量的推文中总结了这个"安装顺序"：

| 锁 | 对应工具 | 核心功能 |
|---|---------|---------|
| 一号锁·秘 | `direnv` + Secrets Manager | 隔离密钥，防止 API Key 泄露 |
| 二号锁·度 | `litellm` / `portkey` 模型代理 | 控制用量、预算上限、响应缓存、PII 脱敏 |
| 三号锁·录 | `uv` + Git commit（每次 eval 通过即提交） | 记录完整状态（prompt + code + model），可一键回滚 |
| 四号锁·察 | `mitmproxy` 拦截所有 LLM 流量 | 实时监控 agent 行为：静默重试、完整 prompt、token 成本、注入攻击 |
| 五号锁·验 | `inspect-ai` 评估框架 | 结构化、可复现的 agent 行为评估 |

**核心洞见：顺序不是随意的，而是依赖链。**

1. **隐私优先** — 如果密钥在泄漏，后面一切都是在沙滩上建城堡
2. **成本其次** — 密钥安全后，才能控制 agent 的无限制消耗
3. **可复现第三** — 花费可控后，才值得记录每次状态（否则记录本身也在浪费）
4. **可观测第四** — 状态可回溯后，才有意义去监控实时行为
5. **评估最后** — 前四层就位后，评估结果才是可信的

一个补充实践：每个项目维护一份 `lessons.md`，记录踩过的坑、有效的方案、下一步要试什么。这不是第六把锁，而是老师傅的口述——把每个作坊的经验变成可传承的知识。
