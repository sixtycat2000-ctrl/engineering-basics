# 老陈的出海令

老陈是铜锣湾的引航站长。三十年引航生涯，闭着眼都能摸进港。

去年站里配了一条新船——"铁鲫鱼"。无人驾驶，自动导航，不疲倦、不畏缩、二十四小时跑。全站上下都乐坏了，觉得以后引航这活儿就不用人干了。

第一回出任务，三号泊位要测航道水深。老陈对着铁鲫鱼的话筒说了一句话：

"去三号泊位，量水深。"

铁鲫鱼嗖地就走了。两个小时候后回来，报告水深数据一切正常。老陈刚要满意，码头主管找上门来，脸都绿了：铁鲫鱼测水深的时候横穿了两条货运航线，差点和一艘万吨轮撞上。它只顾着量水深，完全没管自己在什么水域里跑。

老陈挠了挠头。第二回学聪明了：

"去三号泊位，沿主航道中线走，量水深。水深低于五米的地方标红。"

铁鲫鱼又走了。这回航线规规矩矩，水深数据也标得清清楚楚。可等老陈拿到报告一看——铁鲫鱼不光量了三号泊位，连一号、二号、四号、五号全量了一遍。它觉得"既然到了，顺便都量了效率更高"。

铁鲫鱼整整跑了一天，电池差点耗尽。老陈只需要三号泊位的数据。

"你得跟它说清楚，只量三号。"隔壁站的老郑路过，听见这事儿，乐了。

第三次，老陈把指令改得更精确：

"去三号泊位，沿主航道中线走，只量三号泊位的水深，低于五米标红。量完直接回来。"

这回铁鲫鱼出发得干脆利落。航线安全，范围也没跑偏。可到了三号泊位入口，它停住了——主航道中线有一艘抛锚的渔船堵着，过不去。

铁鲫鱼在入口处原地转圈。转了一个小时、两个小时。它心想：指令说"沿主航道中线走"，但现在中线走不通了。它既没有换路——因为指令没说可以换——也没有回来——因为任务还没完成。

六个小时后，电池报警，铁鲫鱼才慢悠悠地返航，什么数据也没带回来。老陈站在码头等了一整天，差点把海鸥数了个遍。

"你就没告诉它，路走不通了该怎么办？"老郑叼着烟，一副不出所料的表情。

老陈这回是真犯了难。他摊开纸，想总结到底哪里出了问题。第一次是没说边界，第二次是没说范围，第三次是没说走不通了怎么办。

"你缺的不是经验，"老郑凑过来，掏出一张皱巴巴的纸，"你缺的是一套格式。"

纸上画了六个格，每个格里一行字。老郑说这是他引了二十年无人船总结出来的——他叫它"出海令"：

1. **终点在哪** — 到底要什么结果，一句话说清楚
2. **怎么算到了** — 看见什么信号才算任务完成
3. **什么不能碰** — 绝对不能违反的规矩
4. **只能在哪儿跑** — 路线、范围、工具，画个圈
5. **岔路口怎么选** — 遇到多条路时按什么标准挑
6. **走不通了就回来** — 别硬撑，回来报告：走了哪几条路、看见什么、卡在哪

老陈将信将疑地按这六个格写了一份新指令：

"去三号泊位量水深，数据误差不超过十厘米（终点+验证）。航行全程保持在主航道内，不得穿越货运航线（约束）。只量三号泊位，不走其他航道（边界）。遇到障碍优先选择右侧绕行，绕行距离超过一海里则掉头（判断准则）。如果三小时内无法到达，或航道完全堵塞，立即返航并报告已走过的路线、观测到的障碍、需要什么支援才能继续（死胡同报告）。"

铁鲫鱼出去了。途中遇到渔船，它右转绕行——绕了零点三海里，在一海里以内，继续前进。到达三号泊位，只量了三号，数据标红，返航。

一个半小时，干干净净。

从那以后，老陈再也没改过出海令的格式。站里新来的年轻人总觉得六个格太多，写起来麻烦。老陈也不多解释，只是把那三份失败的旧指令拍在桌上，说：

"你觉得麻烦，还是觉得等六个小时什么都拿不回来麻烦？"

## 💡 概念解析：自主 Agent 任务委派模板（Autonomous Agent Task Delegation Prompt）

故事里的"铁鲫鱼"就是 AI Agent，"出海令"就是**自主任务委派模板**。

给 AI Agent 下达任务时，最常见的错误是只写一句话——"帮我搞定这件事"。Agent 确实能跑，但它不知道边界在哪、怎么验证做对了、遇到阻碍该怎么办。结果是：要么跑了不该跑的地方（缺少约束），要么做了不需要做的事（缺少范围），要么卡住后原地打转（缺少死胡同报告），要么你以为它做完了但其实没达标（缺少验证标准）。

模板的核心是六个要素：

1. **Goal（目标）**— 不是"改进一下"，而是"达到什么状态"。越具体越好。
2. **Verification（验证）**— 不是"看起来不错"，而是"测试通过、指标达到 X"。让成功可证伪。
3. **Constraints（约束）**— 不能触碰的红线。防止 Agent 在探索过程中搞破坏。
4. **Scope（边界）**— 只能用什么工具、只碰什么文件、只做什么操作。防止范围蔓延。
5. **Decision Heuristic（判断准则）**— 多条路可走时，Agent 按什么优先级选择。防止犹豫不决。
6. **Dead-end Protocol（死胡同报告）**— 走不通时必须停下来，报告：试了什么、看到了什么、卡在哪、需要什么才能继续。防止无限循环。

这六个要素缺一不可。跳过任何一个，Agent 的可靠性都会显著下降——就像老陈的前三次出海一样，每次都只少了一个格，每次都翻了车。
