# 📖 每日工程寓言 — Git Worktree + Bare Clone

老周是镇上唯一的钟表匠，手艺一流，活儿多到接不过来。他的工作间只有一张桌子。

每天面前摆着五六个待修的钟表，他只能修一个，收一个，修一个，收一个。忙得团团转的时候，李老板推门进来："我那怀表好了没？"

老周低头看——桌上散落着张老师挂钟的齿轮，拆到一半。他叹了口气，把零件一个个放进格子盒里，从柜子深处翻出李老板怀表的半成品，重新摆上台面。

这样的场景，每天要上演七八次。格子盒堆了一柜子，每个盒子上贴着"进行中"。

---

一天，远游归来的师兄登门。站在门口看了一刻钟，说了句："你一半的时间不是在修表，是在搬家。"

老周嘴硬："修表就得这样。"

"不用。"师兄把他带到自己的工作室。

推开门，老周愣住了——没有工作台。正中央是一扇铁门，门后是一间密室，密密麻麻全是档案柜，存放着每一只钟表的完整维修记录和零件清单。"这间屋子只存档案，不许干活，"师兄说。

然后师兄推开走廊两侧的房门。一号房、二号房、三号房。每间各有一张干干净净的工作台。一号台上是李老板的怀表，零件散开着，原封不动；二号台上是张老师的挂钟，工具摆了一半；三号台上是王医生的腕表，还没动过。

"三张台子同时推进，谁也不用给谁腾地方。"

老周看得眼睛发亮。

"我也搞！"转念一想，"三张台子，三套工具？我那套德国镊子八千块……"

师兄笑了，推开走廊尽头的一间工具房。"一套就行。所有台子共享这一间，不管你开几张台子，工具只买一份。开新台子，走两步过来拿，用完放回来。"

---

一个月后，老周的工作室改头换面。

走廊尽头是铁门密室——他叫它"档案库"，只存记录，不碰活。两侧四间房，四张台子，同时开工。走到哪间，活儿就在那里等着，不用收，不用找，坐下就干。

他还发现一个妙招：在一号台干着活，听到二号台那边的活儿有新进展，不用跑过去。喊一声"把二号台的最新记录拉过来"，走廊里的学徒就去档案库里取最新的，替他更新好。

镇上人都说老周学会了分身术。他一个人干四个人的活儿，从来不慌不忙。

---

直到有一天出了事。

他在一号台修着李老板的怀表，忽然想到一个棘手的问题，想去二号台上也打开李老板的档案查一下笔记。刚伸手去档案库，被学徒小陈拦住了。

"师傅，系统不让。同一份档案，不能在两张台子上同时打开。"

老周愣了："为什么？"

"您正在按这份档案调游丝呢。我要是在二号台上也改了这份档案，您照着旧版本做下去，最后拼出来的表就对不上号了。两只手同时改一张纸，一定打架。"

老周想了想，明白了。"那我需要查怎么办？"

"抄一份副本。您拿原件继续在一号台干活，我在二号台上用副本新建一条分支记录。两份档案各自独立演进，最后合并。"

从此工作室立下铁律：**同一份档案，同一时间只许出现在一张台子上。** 想跨台参考，就建副本分支。

有人问老周秘诀，他总是笑着说："不是我变快了。是我不搬家了。"

---

## 💡 概念解析：Git Worktree + Bare Clone

这个故事讲的是 **Git Worktree 配合 Bare Clone** 的工程实践——一种让开发者同时处理多个分支而不需要反复切换或暂存代码的方法。

**对应关系：**

| 寓言 | 实际概念 |
|------|---------|
| 档案库（铁门密室，只存档案不干活） | **Bare Clone**（`git clone --bare`）——一个只有 Git 历史记录、没有工作文件的裸仓库 |
| 多张工作台 | **Worktree**（`git worktree add`）——从同一个 bare clone 派生出的多个工作目录 |
| 格子盒收零件 | **`git stash`**——老周以前的痛点，反复暂存和恢复代码 |
| 工具房共享一套工具 | **依赖共享**——pnpm 硬链接、Cargo 共享 target/，多个 worktree 共用同一份依赖，避免磁盘爆炸 |
| 隔空喊话更新二号台 | **`git -C ../main pull`**——无需切换目录就能更新其他 worktree |
| 同一份档案不能两台打开 | **分支锁定**——Git 不允许两个 worktree 同时检出同一个分支（`fatal: 'dev' is already checked out`） |
| 抄副本建分支 | **在第二个 worktree 创建子分支**（`dev-bugfix`）来规避锁定 |

**核心价值：** 传统工作流中，开发者只有一个工作目录，切换分支要么用 `git stash`（暂存未完成的改动），要么用 `git checkout`（可能丢代码）。Git Worktree 让你从同一个仓库同时挂载多个工作目录，每个目录对应不同分支。配合 Bare Clone（裸仓库），把 `.git` 目录和代码文件彻底分离——裸仓库是中央档案库，worktree 是各张独立工作台。

这在 AI 编程时代尤其重要：让 Claude Code 在 feature-A 的 worktree 里写代码，同时你在 main 的 worktree 里做 code review，互不干扰，不用 stash，不用等。多人、多 Agent、多分支，并行推进。

> "不是我变快了。是我不搬家了。"
